# Wukuro

Wukuro は、WaaS を基盤とする Unity 向けのイベントスクリプトのフレームワークです。会話、演出、分岐などのゲーム内のイベントを Rust または MoonBit で記述し、WebAssembly のコンポーネントとして Unity 上で実行します。

:::warning
Wukuro は**非常に実験的**な段階にあり、破壊的な変更が行われる可能性があります。
:::

## 特徴

- **プログラミング言語でイベントを記述できる**: 条件分岐、繰り返し、関数による共通化など、Rust または MoonBit の機能をそのまま使ってイベントを記述できます。どちらの言語でも同じ機能を使え、1 つのプロジェクトで併用できます。
- **1 つのファイルに複数のエントリポイント**: エントリポイントとして指定した関数（Rust では `#[entry]`、MoonBit では `#wukuro.entry`）がエントリポイントになります。同じファイル内の定数や関数を、複数のイベントで共有できます。
- **インスペクタで引数を設定できる**: エントリポイントの引数は、Unity のインスペクタからシーン内のオブジェクトやアセットを指定して渡せます。オブジェクトの型を制約することもできます。
- **ゲームに合わせて拡張する前提の設計**: Wukuro 自体が提供する機能は、待機、変数、ログ、ダイアログなどの基本的なものに限られます。カメラ、サウンド、アイテムなどのゲーム固有の機能は、ゲーム側で C# のインターフェースとして定義して追加します。

## 構成

Wukuro は、Unity パッケージと、言語ごとのゲスト側のライブラリから構成されます。

| 名前 | 種類 | 内容 |
| --- | --- | --- |
| `com.ruccho.wukuro` | Unity パッケージ | スクリプトの実行、エントリポイントの参照、インスペクタ、MoonBit Importer 用のエントリポイントの生成器、`wukuro:core` と `wukuro:dialog` のホスト側の実装 |
| `wukuro` | Rust クレート | `wukuro:core` のバインディング、`#[entry]`、テキストとオブジェクトの型の補助 |
| `wukuro-macro` | Rust クレート | `wukuro` が用いる手続きマクロ |
| `wukuro-dialog` | Rust クレート | `wukuro:dialog` のバインディングと、メッセージの表示の補助 |
| `ruccho/wukuro` | MoonBit のモジュール | `wukuro:core`（パッケージ `ruccho/wukuro`）と `wukuro:dialog`（パッケージ `ruccho/wukuro/dialog`）のバインディングと、テキスト、メッセージ、オブジェクトの型の補助 |

クレートは [crates.io](https://crates.io/) で、MoonBit のモジュールは [mooncakes.io](https://mooncakes.io/) で公開しています。

ホストとスクリプトの間の関数と型は、[Component Model](../component-model/index.mdx) の WIT のパッケージとして定義されています。

- `wukuro:core`: コンテキスト、引数、変数、待機、テキストなどの基本的な機能
- `wukuro:dialog`: ダイアログの表示（メッセージ、選択肢、フェード）

ゲーム固有の機能は、同じ方法で独自の WIT のパッケージとして追加します（[機能の追加](./extending.mdx)）。

## 言語

Rust と MoonBit は、Unity 上でスクリプトをビルドするインポーターと、バインディングや補助を提供するゲスト側のライブラリによってサポートしています。各ページでは、両方の言語を並べて説明します。

ホストとスクリプトの間のインターフェースは WIT で定義されているため、インポーターやゲスト側のライブラリがなくても、C、C++、Go、JavaScript など、WebAssembly のコンポーネントをビルドできるほかの言語でもスクリプトを記述できます。エントリポイントの WIT を書き、Unity の外でコンポーネントをビルドするなど、手間は多くなります（[ほかの言語の利用](./other-languages.mdx)）。
