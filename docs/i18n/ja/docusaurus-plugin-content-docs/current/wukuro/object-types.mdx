# オブジェクトの型

エントリポイントの `Object` 型の引数には、任意の `UnityEngine.Object` を渡せます。引数の型を `ObjectOf<T>`（MoonBit では `ObjectOf[T]`）にすると、インスペクタは型 `T` のオブジェクトだけを受け付けるようになります。型の定義の起点は C# です。

## 型を宣言する {#declaring-types}

スクリプトの引数として受け取る型を、アセンブリ属性 `WukuroObjectType` で宣言します。

```csharp
using UnityEngine;
using UnityEngine.Playables;
using Wukuro;

[assembly: WukuroObjectType(typeof(Transform))]
[assembly: WukuroObjectType(typeof(PlayableDirector))]
[assembly: WukuroObjectType(typeof(MyGame.Door))]
```

## スクリプトの型を生成する {#generating-the-types-of-scripts}

宣言した型ごとに、スクリプトの言語のマーカー型を生成し、ゲームのゲスト側のライブラリに含めます。生成には `WukuroObjectTypeExporter`（`Wukuro.Editor`）を使います。マーカー型は C# の型の名前（`Namespace.TypeName, AssemblyName`）を持ちます。

<Tabs groupId="language">
<TabItem value="rust" label="Rust">

```csharp
var types = WukuroObjectTypeExporter.CollectTypes();
var source = WukuroObjectTypeExporter.GenerateRust(types, "// generated from WukuroObjectType\n");
File.WriteAllText("rust/my-game/src/object_types.rs", source);
```

生成されるコードは `wukuro::ObjectType` を実装します。

```rust
/// `UnityEngine.Transform`
pub struct Transform;

impl ::wukuro::ObjectType for Transform {
    const TYPE_NAME: &'static str = "UnityEngine.Transform, UnityEngine.CoreModule";
}
```

生成したファイルを、クレートのモジュールとして公開します。

```rust title="rust/my-game/src/lib.rs"
pub mod object_types;
```

</TabItem>
<TabItem value="moonbit" label="MoonBit">

```csharp
var types = WukuroObjectTypeExporter.CollectTypes();
var source = WukuroObjectTypeExporter.GenerateMoonBit(types, "// generated from WukuroObjectType\n");
File.WriteAllText("moonbit/my-game/object_types/object_types.mbt", source);
```

生成されるコードは、属性 `#wukuro.object_type` を付けた構造体を宣言します。

```moonbit
///|
#wukuro.object_type("UnityEngine.Transform, UnityEngine.CoreModule")
pub struct Transform {}
```

マーカー型は、スクリプトの中か、スクリプトが依存するローカルのモジュールのパッケージ（`moon.pkg` を持つゲームのモジュールの `object_types` など）に置けます。

</TabItem>
</Tabs>

C# の宣言を変えたときに自動で生成し直すには、コンパイルの後に生成を行うエディタ拡張を用意し、生成したファイルを `ExternalFileDependency.Register` で登録します（[ゲームのデータからコードを生成する](./extending.mdx#generating-code-from-the-data-of-the-game)）。

## 型付きの引数を使う {#using-typed-parameters}

<Tabs groupId="language">
<TabItem value="rust" label="Rust">

```rust
use wukuro::{entry, ObjectOf};
use wukuro::types::Context;
use my_game::object_types::{Door, Transform};

#[entry]
fn open_door(cx: &Context, door: &ObjectOf<Door>, camera_target: &ObjectOf<Transform>) {
    let game = my_game::functions::get_game_module(cx);
    game.move_camera(camera_target, 1.0);
    // ...
}
```

`ObjectOf<T>` は `Object` に変換（Deref）できるため、`&Object` を受け取る関数にそのまま渡せます。

</TabItem>
<TabItem value="moonbit" label="MoonBit">

```moonbit
///|
#wukuro.entry
pub fn open_door(
  cx : @wukuro.Context,
  door : @wukuro.ObjectOf[@object_types.Door],
  camera_target : @wukuro.ObjectOf[@object_types.Transform],
) -> Unit {
  let game = @functions.get_game_module(cx)
  game.move_camera(camera_target.object(), 1.0)
  // ...
}
```

`object()` は `ObjectOf[T]` の `Object` を返します。

</TabItem>
</Tabs>

インスペクタでは、引数の欄がその型の ObjectField になり、異なる型の値を設定するとエラーが表示されます。GameObject は、その型のコンポーネントを持つ場合にだけ受け付けます。

## 仕組み {#how-it-works}

エントリポイント（Rust では `#[entry]`、MoonBit では **Wukuro Entry Points**）は、`ObjectOf` の引数の型名を WebAssembly のバイナリのカスタムセクション `wukuro-entry-types` に記録します。インスペクタは `WukuroEntryPoints.GetObjectTypes(script)` で記録を読み取り、型を確認します。WIT での引数の型は `borrow<object>` のままであり、型の制約はインスペクタでの入力の確認にだけ使われます。

実行時には、ホスト関数が `WukuroObjects.Get<T>` でオブジェクトを取り出すときに型が確認されます。
