# `wit2waas` の使用

`wit2waas` は、WIT で記述されたインターフェース等を C# のインターフェース定義に変換するスタンドアロンツールです。  
[Binding Generator](./binding-generator/) と組み合わせることで、WIT で記述されたインターフェースを C# 上で簡単に扱うことができます。

### インストール

#### ビルド済みバイナリ

ビルド済みバイナリのアーカイブが、各 [GitHub のリリース](https://github.com/ruccho/WaaS/releases)に添付されています。お使いのプラットフォーム向けのアーカイブをダウンロードして展開し、`wit2waas` を `PATH` の通ったディレクトリに配置してください。

| プラットフォーム | アーカイブ |
|---|---|
| Windows (x86_64) | `wit2waas-x86_64-pc-windows-msvc.zip` |
| macOS (Apple シリコン) | `wit2waas-aarch64-apple-darwin.tar.gz` |
| macOS (Intel) | `wit2waas-x86_64-apple-darwin.tar.gz` |
| Linux (x86_64) | `wit2waas-x86_64-unknown-linux-gnu.tar.gz` |

#### ソースからのビルド

あるいは、[Rustのツールチェインをインストール](https://www.rust-lang.org/ja/tools/install)してから、次のコマンドで `wit2waas` をインストールします。

```sh
cargo install wit2waas
```

### 使い方

#### WIT の構成

あらかじめ、次のようなディレクトリ構成で WIT を保存します。

```
- wit
  - <your wit>.wit
  - <your wit>.wit
  - <your wit>.wit
  - deps
    - <dependency package>
      - <dependency>.wit
      - <dependency>.wit
    - <dependency package>
    - <dependency package>
```

:::info
[`wit-deps`](https://github.com/bytecodealliance/wit-deps) などのツールを使用すると、パッケージレジストリ等からパッケージの依存関係を構成することができます。
:::

#### `wit2waas` の実行

次に、`wit` フォルダを含むディレクトリで `wit2waas` を実行します。

```sh
wit2waas
```

結果が `out` フォルダに出力されます。この中に含まれる `*.cs` を C# プロジェクトに配置してください。

### オプション

```sh
$ wit2waas --help
Usage: wit2waas [OPTIONS]

Options:
  -w, --wit-dir <WIT_DIR>  [default: wit]
  -o, --out <OUT>          [default: out]
  -h, --help               Print help
  -V, --version            Print version
```

### `init` アクセサに関する問題

`wit2waas` はレコードの型定義を作成する際に `init` アクセサを使用します。  
Unity など .NET 5 未満の環境ではデフォルトではコンパイルできませんが、以下のコードを追加することでコンパイル可能になります。

```csharp
namespace System.Runtime.CompilerServices
{
    internal static class IsExternalInit { }
}
```
